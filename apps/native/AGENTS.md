# Native app boundaries

- Every Rust source file under `apps/native` must contain at most 400 physical lines, including blank lines and comments. This includes build scripts, tests, and new files that are not yet referenced by a module. Generated build output under `target` is excluded.
- The pre-commit hook checks staged Rust contents with the same line-count rule, and the native build script also enforces it for Cargo builds, checks, and tests, including CI. Enable the hook for each clone with `git config --local core.hooksPath .githooks`. Keep the checks enabled; do not bypass them with generated source, `include!`, compressed formatting, or an allowance for existing files.
- Split files by responsibility. Keep desktop state, widgets, native dialogs, and painting here. Feature crates own repository observation (`factory-repository`), authored plans and group import (`factory-plan`), session persistence (`factory-session`), remote repository access and its credentials (`factory-remote-repository`), layout calculations and scheduling (`factory-layout`), and layout diagnostics (`factory-layout-comparison`).
- Preserve the existing UI and behavior when reorganizing modules. Keep shared crates independent of eframe and the desktop event loop.
